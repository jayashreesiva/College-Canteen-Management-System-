🍴 College Canteen Management System

📌 Project Overview

The College Canteen Management System is a web-based application designed to simplify and manage the daily activities of a college canteen. It allows students and staff to view the available food items, place orders, and manage their orders easily.

The system helps reduce waiting time, minimizes manual work, and provides a more organized way to handle canteen operations.

---

🎯 Objectives

- To provide an easy-to-use online canteen ordering system.
- To reduce long queues and waiting time.
- To display food items and their prices clearly.
- To simplify the process of placing and managing orders.
- To maintain organized order information.
- To improve the overall efficiency of college canteen operations.

---

✨ Features

👨‍🎓 Student Features

- Student registration and login
- View available food items
- View food prices
- Add items to cart
- Place food orders
- View order details
- Track order status

👨‍🍳 Canteen/Admin Features

- Admin login
- Add new food items
- Update food item details
- Remove unavailable items
- View student orders
- Update order status
- Manage menu items
